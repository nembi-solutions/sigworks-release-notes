# Versão 1.58

A versão 1.58 introduz a funcionalidade de **Importação de Desembolso**, permitindo que a distribuição de unidades ao longo dos meses seja definida diretamente no momento do upload, tornando o processo mais flexível, preciso e integrado ao planejamento do sistema.

## Destaques

Essa funcionalidade foi pensada para facilitar o controle de desembolso mensal, oferecendo:

- Importação de distribuição mensal diretamente via template
- Geração automática de cabeçalhos dinâmicos com base no período da linha de base
- Redução de ajustes manuais após o cadastro
- Maior padronização no processo de planejamento
