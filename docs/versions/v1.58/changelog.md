# Changelog – v1.58

## Adicionado
- Funcionalidade de **Importação de Desembolso**:
  - Novo campo **"Importar Desembolso?"** no cadastro de Linha de Base;
  - Geração de template com cabeçalho dinâmico, contendo os meses correspondentes ao período configurado;
  - Possibilidade de informar a distribuição de unidades mensalmente no momento do upload.
  
  → [Importação de Desembolso / Manual de uso](../../modules/upload_desembolso/index.md)

## Alterado
- Processo de upload de Linha de Base para suportar dados de desembolso mensal;
- Validações para garantir consistência entre período da linha de base e os meses do template.
